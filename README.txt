Dial Sender - mengirim watchface ke jam Advan On Posh

1. Buat repositori baru di github.com (tombol "New"), nama bebas, isi kosong.
2. Klik "uploading an existing file", seret SEMUA isi folder ini (app, .github, build.yml, dll), lalu "Commit changes".
   Jika folder .github tidak ikut: klik Add file > Create new file, ketik nama
   .github/workflows/build.yml dan tempel isi file build.yml, lalu Commit.
3. Buka tab "Actions", tunggu tanda centang hijau (sekitar 3-5 menit).
4. Klik hasil build terbaru, unduh "DialSender-apk" di bagian Artifacts, ekstrak zip-nya, pasang app-debug.apk di HP.
5. Ikuti petunjuk yang tampil di aplikasi.
